# Glossary

| Term | Meaning |
|------|---------|
| **Hull** | Ship HP. When hull reaches 0 the mission is lost. |
| **Shield** | Buffer in front of hull; absorbs all incoming damage first; regenerated by generator pulses. |
| **Energy** | Resource pool drawn by front/rear weapons (per shot), shield (per pulse), and motor (constant). Produced by the generator. |
| **Generator** | Produces energy/tick; periodically fires a pulse that restores a fraction of shield capacity. |
| **Motor** | Scales the mission wave timeline speed. Faster = more danger, but earns time-stars and more coins per minute. Draws energy constantly. Always active — not toggleable. |
| **Conveyor** | The single-file queue of enemies moving toward the ship. Game state is one-dimensional: each enemy is just a distance value. |
| **Blocker** | An enemy that pauses the wave timeline while alive. Killing one grants a bonus support call. |
| **Brownout** | When energy drops below 30% of capacity, the weapon fire interval stretches (up to 2×). Never stops firing entirely — a slope, not a cliff. |
| **Support call** | A scheduled moment when a helper ship flies by and offers 3 cards to pick from. |
| **Subscription** | A shop purchase that adds a pool of bonuses to the support call draw. Multiple can be owned simultaneously. Reached in-game via **Dispatch Reinforcements**, not a literal "Subscriptions" tab — see [Shop & Modules](05-shop-and-modules.md). |
| **Card / Run modifier** | A one-run effect picked from a support call offer. Expires when the mission ends. |
| **Side weapon** | A manual-fire, limited-ammo weapon tapped by the player during combat. |
| **Reserve supply** | A persistent active boost purchased in the shop. Charges auto-refill every mission; player taps mid-combat to use. |
| **Star** | Earned by completing mission benchmarks. Pays a coin bonus on first earn. Also an **earned-total threshold gate** — some shop items require having earned N stars lifetime, meaning even infinite coins can't buy everything immediately. Stars are never spent and never lost — nothing in the shop deducts or refunds them (corrected 2026-07-18; this row previously described stars as a spendable currency, which the shop code never implemented). |
