# Game Philosophy

The game is about tuning your spaceship and playing levels with various mechanics.

The gameplay of the level is that the ship is stationary and enemies fly towards in a single line. Some enemies can move towards the ship, some stay stationary until destroyed. Some enemies can shoot the ship. Some enemies can boost other enemies. Some enemies can nerf the player.

The spaceship contains of modules:

- The ship type itself with some amount of hull (ship life points)
- Front weapon for high single target damage.
- Rear weapon for area-of-effect weapon.
- Generator that generates energy.
- Shield that protects hull and recharges quickly
- Side weapons with limited amount of ammo
- A subscription to a support company that will provide random bonuses from a pool
- Motor that will move the ship faster through missions

Player will get "coins" for killing enemies. Using these coins, player can buy upgrades from the shop. The idea is that every module is using energy in some form and player must balance between offense and defense to make it work.

# Shop

Player cannot own multiple modules of the same type. They can own only one type that is always equipped. Player can always sell/downgrade every module for the full acquisition cost.

Every module comes with multiple types and every type have also several upgrade levels.
